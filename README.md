# NavArena 开发者文档

这是 NavArena 具身导航平台的在线文档站点，涵盖资产预处理、数据生成与导航评测的使用指南与 API 参考。

## 查看文档

- **在线文档**：<https://ei-nav.github.io/NavArena-Doc/>
- **本地预览**：

```bash
pip install -r requirements.txt
mkdocs serve
```

访问 http://127.0.0.1:8000 即可预览。

## 文档结构

| 模块 | 说明 |
|------|------|
| 快速开始 | 安装与入门教程 |
| 规范定义 | 核心概念、资产格式、数据格式 |
| 资产预处理 | navarena-forge 使用指南 |
| 数据生成器 | navarena-gen 使用指南 |
| 评测框架 | navarena-bench 使用指南 |
| API 参考 | 数据生成器与评测框架 API |
