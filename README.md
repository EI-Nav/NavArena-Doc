# NavArena Developer Documentation

This is the online documentation site for the NavArena embodied navigation platform, covering asset preprocessing, data generation, and navigation evaluation guides along with API references.

## View the Documentation

- **Online docs**: [https://ei-nav.github.io/NavArena-Doc/](https://ei-nav.github.io/NavArena-Doc/)
- **Local preview**:

```bash
pip install -r requirements.txt
mkdocs serve
```

Visit [http://127.0.0.1:8000](http://127.0.0.1:8000) to preview locally.

## Documentation Structure


| Module               | Description                               |
| -------------------- | ----------------------------------------- |
| Quick Start          | Installation & getting started tutorial   |
| Definitions          | Core concepts, asset format, data format  |
| Asset Preprocessing  | navarena-forge user guide                 |
| Data Generator       | navarena-gen user guide                   |
| Evaluation Framework | navarena-bench user guide                 |
| API Reference        | Data generator & evaluation framework API |
